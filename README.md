## 1. Executive Summary & Methodology

We executed an end-to-end, fail-closed cross-survey hunt comparing **NVSS** (1.4 GHz, 1993–1996, 45" beam, 5σ completeness limit $S_{1.4,\text{lim}} = 2.50\text{ mJy}$, VizieR `VIII/65/nvss`) against **VLASS Epoch 1** (3.0 GHz, 2017–2019, 2.5" beam, VizieR `J/ApJS/255/30/comp` & `J/ApJS/255/30/subtile`).

To eliminate every failure mode observed in prior XENO-5 attempts (specifically: (a) ungrouped lobes of extended FR-II radio galaxies resolved by VLASS's 2.5" beam but blended by NVSS's 45" beam, and (b) silent empty/failed HTTP queries treated as "0 matches"), our pipeline enforces **four strict technical safeguards**:
1. **Multi-Survey Component Grouping & Lobe Exclusion (Gate 1)**: Every candidate must be an isolated single-Gaussian island (`SCode = 'S'`, deconvolved major axis `DCMaj < 3.0"`, nearest VLASS neighbor `NNdist > 120"`), have **0 NVSS counterparts within 60"** (6× the required 10" radius), and have **0 counterparts within 60"** across **FIRST** (`VIII/92/first14`, 1.4 GHz, 5.4" beam), **TGSS ADR1** (`J/A+A/598/A78/table3`, 150 MHz), **WENSS** (`VIII/62/wenss`, 325 MHz), and **LoTSS DR2** (`J/A+A/659/A1/catalog`, 144 MHz). This killed 3 candidates (`J000424.01+235724.5`, `J022403.24+293937.2`, `J091150.42+334124.8`) that appeared absent in NVSS but were detected at 144 MHz in LoTSS DR2.
2. **Explicit Spectral-Index Flux Math (Gate 1)**: For an undetected NVSS source ($S_{1.4} < 2.50\text{ mJy}$), a standard optically thin synchrotron spectrum ($S_\nu \propto \nu^\alpha$ with $\alpha = -0.70$) predicts a 3.0 GHz flux density of:
   $$S_{3.0,\text{exp}} = 2.50\text{ mJy} \times \left(\frac{3.0\text{ GHz}}{1.4\text{ GHz}}\right)^{-0.70} = 2.50 \times 0.5868 = 1.467\text{ mJy}$$
   All **5 primary surviving candidates** have $S_{3.0} \in [10.68, 24.79]\text{ mJy}$, yielding **spectral-index-corrected flux ratios of $7.28\times$ to $16.90\times$** (all well above the $\ge 5.0\times$ threshold), and Candidates #1–#4 even exceed $5.0\times$ in raw uncorrected flux ratio ($5.89\times$ to $9.91\times$, corresponding to extreme inverted spectral indices $\alpha_{1.4}^{3.0} > +2.33$ to $+3.01$).
3. **Second VLASS Observation + FITS Cutout Verification (Gate 3)**: Every surviving candidate has `DupFlag = 1` with a verified `QualFlag = 0` partner row (`DupFlag = 2`) in `J/ApJS/255/30/comp` JOIN `J/ApJS/255/30/subtile`, meaning the source was **independently observed and detected in two overlapping VLASS subtiles / tiles / scheduling blocks** (often days to weeks apart, e.g., Tile `T22t03` on `2019-04-30` and Tile `T21t03` on `2019-05-13` for Survivor #4), **AND** is independently confirmed in the live 3.0 GHz FITS image cutout from `LegacySurvey` (`layer=vlass1.2`).
4. **Evidence Rule Compliance**: Every cross-match query is validated for `HTTP 200` and a non-empty structured payload (`> 2,000 bytes` for VizieR ASU-TSV, valid JSON metadata + data array for TAPVizieR/SIMBAD, and valid ASCII table header for NED), with the raw catalog responses quoted verbatim below.
